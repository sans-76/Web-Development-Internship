
# ShopEasy - Mini E-Commerce Website

## Project Description

ShopEasy is a responsive mini e-commerce website created
using HTML, CSS and JavaScript.

The project demonstrates basic web development concepts
including responsive design and JavaScript interactions.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Main Features

- Responsive navigation
- Hero section
- Product cards
- Product details modal
- Special offers slider
- FAQ accordion
- Contact section
- Responsive mobile design

## JavaScript Features

### Product Modal

Users can click "View Details" to open a popup
containing product information.

### Offers Slider

Users can use the previous and next buttons
to view different offers.

### FAQ Accordion

Users can click a question to show or hide
the answer.

## Responsive Design

The website works on:

- Desktop
- Laptop
- Tablet
- Mobile

CSS media queries are used to adjust the layout
for different screen sizes.

## How to Run

1. Open the project folder in VS Code.
2. Open index.html.
3. Use Live Server or open index.html directly
   in a web browser.
4. Test the navigation, product modal, slider
   and FAQ accordion.
